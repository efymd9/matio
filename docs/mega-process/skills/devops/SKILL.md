## Грабли (проверены кровью — не переоткрывать)

<!-- Сюда — только СВОИ проверенные грабли, по мере набивания шишек.
Стартовый набор универсальных граблей от оригинала: -->

1. Проверка «процесс жив» грепом по имени матчит сам себя — экранировать
   (`[k]6`-паттерн) или проверять по данным.
2. Долгие операции по ssh рвутся; nohup умирает вместе с уснувшей
   auto-stop-машиной — писать в файл на машине, исход проверять ПО ДАННЫМ.
3. health-check «зелёный» ≠ «сервис обслуживает»: отказ по соединениям
   обвальный и невидимый для /readyz; триггеры скейлинга — по числу
   соединений, не по CPU.
4. Секреты НИКОГДА не постить в issues/PR; фейковые секреты в тестах
   должны выглядеть фейково (ночной gitleaks).
5. Тестовые БД/кеш-слоты разводить по имени ветки автоматически; явные
   TEST_*_URL — аварийный клапан.
6. (Fly.io) `flyctl deploy` без `--ha=false` создаёт вторую машину — для
   одиночного Redis это расщепление pub/sub и очереди джобов.
7. (Fly.io) `fly machine stop/start` откатывает rootfs к образу —
   артефакты выкачивать до стопа.
